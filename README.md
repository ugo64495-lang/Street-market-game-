# Street Market Challenge VR — WebXR Prototype

First 3D/WebXR prototype: market scene, products, customer category request, score, lives, levels, VR button and controller/cursor selection. WebXR needs HTTPS. On Android, upload these files to GitHub Pages or Netlify. For immersive VR, open the HTTPS page on a compatible Meta Quest browser/headset.

This is a prototype, not the final competition submission. Next: real grab/drop interaction, hand-first interaction, customer character, sound, more levels, menus, polish and competition documentation.
